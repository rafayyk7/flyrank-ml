Predicting Organic Search Traffic Decay: Vectorized Feature Engineering and Leak-Free Gradient Boosted Decision Trees on Large-Scale Search Interaction Data

Abdul Rafay Khan · Machine Learning & Data Systems · August 2026
Abstract

Organic search visibility experiences non-linear traffic decay driven by content staleness, algorithmic shifts, and competitive SERP displacement. In this research, we evaluate whether supervised machine learning models can outperform heuristic rules to predict 30-day traffic loss across multi-domain enterprise search data. Using zero-copy DuckDB vectorized views over 90-day lookback windows, we engineer interaction and position stability signals across anonymized domains. We train a gradient boosted decision tree classifier evaluated via strict 5-Fold GroupKFold validation grouped by client domain to prevent cross-domain target leakage. The resulting model achieves an out-of-fold ROC-AUC of 0.8215 (a 20.1% relative lift over the 0.6842 baseline), powering an automated Content Action Playbook that prioritizes high-value content refreshes with human-in-the-loop governance.

1. Introduction & Problem Statement

Maintaining organic search traffic across enterprise digital portfolios presents an operational challenge: content decay occurs silently before visibility collapses. Standard enterprise workflows rely on static rule thresholds (e.g., flagging any page untouched for 180 days), which generate high false-positive rates and waste finite editorial resources on low-value URLs.

The objective of this research is to construct an end-to-end, leak-free machine learning pipeline that predicts organic search decay on a forward 30-day horizon, while refactoring data ingestion to execute within sub-second SLAs on standard hardware.

2. Data Ingestion & Contract Specification

All evaluations were conducted on the anonymized FlyRank Search Intelligence slice ($N = 10,000$ URL records across 20 client domain clusters). To enforce privacy and enterprise compliance, all raw customer URLs, domains, and specific search query strings were hashed into anonymized identifiers (e.g., url_00042, domain_03).

Lookback Windows & Availability Filtering

  • Historical Feature Window: Strictly bounded to the 90 days preceding the snapshot date (2026-03-31).
  • Target Horizon: Evaluated over the subsequent 30 days post-snapshot.
  • Row Exclusions: Pages marked with is_available = False (404 errors, noindex tags, server timeouts) were strictly filtered out per our Data Contract to prevent training on permanently decommissioned assets.

3. Methodology & Validation Architecture

Baseline Formulation

We established a deterministic baseline action score representing current industry heuristic standards:

Baseline Score = (days_since_update / 365.0) × log10(impressions_90d)

Model Architecture

We implemented a Histogram-based Gradient Boosting Classifier (HistGradientBoostingClassifier). Gradient boosted trees were selected over deep neural networks due to their native handling of non-linear feature interactions, resilience to unscaled skewed distributions (e.g., power-law impressions), and sub-second inference runtime.

Leakage-Free Grouped Validation Design

Standard random K-Fold cross-validation leaks domain-specific style and authority patterns between train and test splits, producing artificially inflated metrics. We implemented a strict 5-Fold GroupKFold validation design grouped exclusively by domain_id. All URLs from any given domain were isolated into either the training split or the validation split, ensuring all reported metrics represent true out-of-domain generalization.

4. Results & Comparative Analysis

Performance was benchmarked across identical 5-Fold GroupKFold splits. The Gradient Boosted model outperformed both the heuristic rule baseline and a shallow Random Forest baseline across all primary evaluation metrics:

Model / Strategy ROC-AUC PR-AUC Precision@Top25% Recall@Top25% F1-Score
Week 4 Heuristic Rule Baseline 0.6842 0.5410 0.6120 0.5890 0.6003
Random Forest Benchmark (Depth 6) 0.7731 0.6685 0.7140 0.6850 0.6992
HistGradientBoosting (Proposed) 0.8215 0.7420 0.7890 0.7540 0.7711

Permutation feature importance analysis identified days_since_update (mean importance = 0.184) and avg_position_30d (mean importance = 0.142) as the primary drivers of traffic decay risk, with ctr_30d providing the critical non-linear dampener.

5. Limitations & Defensible Framing

  • Directional Correlation vs. Causality: The model identifies statistical risk correlations; it does not claim content staleness is the sole causal driver of ranking drops. Algorithmic core updates and competitor backlink velocity remain external confounders.
  • Domain Distribution Shift: Performance was validated on enterprise B2B and content publishing domains. E-commerce sites with high inventory turnover may require retraining with product-stock telemetry.
  • Public-Safe Language: We explicitly frame outputs as "decision-support prioritization queues" rather than autonomous ranking guarantees.

6. Content Action Playbook & Operational Archetypes

Model predictions are mapped into four operational archetypes to direct human editorial bandwidth:

Archetype Condition Criteria Reason Code Prescribed Action
High-Value Decay Risk ≥ 0.65, Imp ≥ 2500, Staleness ≥ 120d RC_STALE_HIGH_IMP Immediate editorial overhaul & data refresh.
SERP Suppression Risk ≥ 0.50, Position ≥ 10, CTR < 2.5% RC_LOW_CTR_DISP Snippet optimization, title A/B test, schema update.
Zombie Content Impressions < 300, Staleness ≥ 270d RC_LOW_DEMAND Audit utility; 301 redirect to canonical parent or prune.
Stable Baseline Risk < 0.50, Stable position & CTR RC_EQUILIBRIUM Passive monitoring; no manual action required.
Strict No-Go Guardrail: Automated mass-deletion of URLs and unreviewed LLM text rewriting directly to production CMS are strictly prohibited.
