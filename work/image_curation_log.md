## ⚖️ 2. Real Capture vs. AI Stand-In Decision Matrix

> **Design Principle:** Never use AI generation to fake real engineering work. Code execution, benchmark outputs, and personal identity must always be 100% authentic captures.

* **Real Headshot over AI Avatar:** An AI-generated avatar destroys credibility on a technical engineering portfolio. A real photo demonstrates authentic ownership of the capstone work.
* **Real Terminal Output over AI UI Mockups:** AI image generators synthesize fake syntax, broken indentation, and hallucinated metrics (e.g., misspelled `pd.read_csv`). Real terminal captures prove working code and actual benchmark metrics.

## 🗑️ 4. Ruthless Curation: Rejection Log (Graded Discernment)

### Rejected Image 1: Generated AI Code Editor Preview
* **Prompt Used:** `"Realistic screenshot of Python code inside modern dark mode IDE displaying machine learning pipeline"`
* **Why It Was Rejected:** The model rendered visually pleasing editor UI panels, but the code contained gibberish syntax (hallucinated functions like `def model_predict_data():;`) and inconsistent indentation. Including fake code in an engineering portfolio undermines technical capability. Replaced with a real VS Code screenshot.

### Rejected Image 2: Alternative Hero Banner Concept
* **Prompt Used:** `"3D render of data warehouse streaming abstract glass cubes and glowing network nodes"`
* **Why It Was Rejected:** The output was visually striking but way too energetic and glossy. It violated our Identity Kit design note (*"quietly modern—designed to let technical engineering work remain the loudest element on the page"*). Replaced with a flat, two-tone geometric vector grid.
